# Image2：图片创作

Image2 用于在几秒内生成高质量视觉素材，适合文章封面、商品配图、海报、社交媒体图片和创意概念图。它最擅长将清晰的视觉描述转化为可选方案。

## 开始前先确定 6 件事

1. **用途**：电商主图、公众号封面、广告海报还是社交媒体配图？
2. **尺寸**：如 1:1、3:4、16:9 或 9:16。
3. **主体**：产品、人物、场景或核心物体。
4. **构图**：主体位置、留白、近景/远景、视角。
5. **风格**：真实摄影、极简、插画、3D、国风等。
6. **限制**：是否要文字、Logo、透明背景，以及不能出现的元素。

## 提示词写法

按“用途 + 主体 + 场景 + 构图 + 光线 + 风格 + 限制”描述。

> 电商方形主图，一瓶无标签玻璃冷萃咖啡置于浅米色背景的木桌中央，右侧保留文案留白，晨间柔光，真实商业摄影，极简高级；无文字、无人像、无水印。

## 迭代方法

- 第一轮：先生成 2–4 个不同构图方向。
- 第二轮：只选择一个方向，明确保留什么、修改什么。
- 第三轮：检查商品外观、边缘、手部、文字和裁切安全区。
- 最终排版：重要文字、价格和小 Logo 建议在设计软件中后加，准确性更高。

## 常见问题

| 问题 | 改进方式 |
| --- | --- |
| 图片风格不稳定 | 明确一种风格并提供参考图或关键词 |
| 主体不突出 | 指定主体位置、景别和背景简洁度 |
| 画面有多余元素 | 加入“仅一个主体”“无文字/无人物”等限制 |
| 文案错误 | 不让模型生成关键文字，后期添加 |

## 使用注意

- 商用前核查人物肖像、品牌标识、作品版权和平台规则。
- 不要用生成图伪造真实新闻、证据或人物言行。
- 参考图仅用于已获授权的内容。
