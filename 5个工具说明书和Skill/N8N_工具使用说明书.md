# n8n：自动化

n8n 是自动化工作流平台，能把表单、邮件、数据库、表格、消息工具和 AI 服务连接起来，让重复、规则清晰的工作自动运行。它的价值不在“自动做一切”，而在稳定地减少人工搬运和重复操作。

## 适合自动化的任务

| 场景 | 触发 | 自动执行 |
| --- | --- | --- |
| 线索处理 | 收到新表单 | 校验信息、写入 CRM、通知销售 |
| 日报汇总 | 每天固定时间 | 读取数据、AI 总结、发送团队 |
| 内容生产 | 素材入库 | 分类、生成初稿、进入审核 |
| 异常监控 | 接收告警 | 归类、创建工单、通知负责人 |

## 搭建流程

1. **画出业务流程**：触发条件、输入、处理规则、输出、失败后的处理方式。
2. **先搭最小版本**：触发器 → 数据读取 → 处理 → 写入/通知。
3. **配置凭证**：统一放在 n8n Credentials，不能写进节点文本或导出 JSON。
4. **用测试数据执行**：检查字段映射、格式、去重和异常分支。
5. **上线前加保护**：错误通知、重试、人工审核和运行日志。

## 工作流示例

> 每天上午 9 点触发 → 读取销售表格 → 计算关键指标 → 交给 AI 生成 200 字摘要 → 写入 Notion → 发送团队消息。

关键节点：Schedule Trigger、数据源节点、Code/Set、AI 节点、Notion 节点、消息节点和 Error Trigger。

## 设计原则

- 一个工作流只解决一个明确问题，便于排错和维护。
- 外部写入前校验必填字段和唯一 ID，避免重复创建数据。
- AI 输出必须视为待检查内容；金额、删除、审批和外发消息最好设置人工确认。
- Webhook 要验证签名或令牌，避免公开入口被滥用。

## 使用注意

- 为重要流程设置失败提醒和负责人，否则异常容易长期无人发现。
- 不在工作流、日志或截图中泄露 API 密钥和客户隐私。
- 修改生产工作流前先复制测试版本，并保留回滚方案。
