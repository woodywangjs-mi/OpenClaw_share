# Seedance：视频生成

Seedance 可根据一句话或分镜描述生成视频片段，适合广告创意、产品展示、短视频开场、氛围镜头和故事概念验证。将它视为高效的视频素材生成器，而不是一次完成整支成片的工具。

## 推荐制作流程

1. **明确成片目标**：平台、比例、时长、受众和想传达的一句话。
2. **拆分分镜**：每个镜头只做一个动作，通常 4–10 秒更容易控制。
3. **写镜头提示词**：包含主体、场景、动作、景别、镜头运动、光线和风格。
4. **先测关键镜头**：产品特写或人物出场先生成，确认视觉方向。
5. **剪辑成片**：把满意镜头导入剪辑工具，再添加字幕、配音、音乐和转场。

## 单镜头提示词公式

`时长/比例 + 主体 + 场景 + 动作 + 景别 + 镜头运动 + 光线/色调 + 风格 + 限制`

> 8 秒、9:16。一杯冰美式放在窗边木桌上，杯壁水珠缓慢滑落；近景，镜头缓慢推进；夏日自然光、清新商业广告风。无文字、杯子不变形、无人物。

## 分镜示例：咖啡短广告

| 镜头 | 内容 | 时长 |
| --- | --- | --- |
| 1 | 阳光透过窗帘，咖啡杯出现在桌上 | 3 秒 |
| 2 | 冰块与咖啡液体特写，镜头推进 | 4 秒 |
| 3 | 成品杯与简短卖点留白 | 3 秒 |

## 提升稳定性的技巧

- 复杂剧情拆成多个镜头，不要一次要求多人、多动作和多场景。
- 每次迭代只修改一两个要素，例如保留镜头，改变光线或节奏。
- 同一产品在多个镜头出现时，使用一致的外观描述和参考图。
- 重要文字、价格和旁白放在后期制作。

## 使用注意

- 发布前确认人物、品牌、素材和音乐的使用权。
- 不得将生成内容包装为真实事件证据或制作误导性真人影像。
- AI 视频可能有动作、物体一致性等瑕疵，成片前必须人工检查。
