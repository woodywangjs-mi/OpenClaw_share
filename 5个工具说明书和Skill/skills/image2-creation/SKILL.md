# Image2 图片创作

将 Image2 用于图片创意、提示词与迭代。先确定用途、平台、比例、主体、风格和品牌限制。

## 工作流程

1. 明确交付规格：用途、尺寸/比例、数量、是否需要透明背景、是否包含文字。
2. 编写提示词：主体、场景、构图、光线、材质、色彩、镜头、风格和禁止元素。
3. 先生成少量方向稿；根据构图、主体准确度和商业可用性选择方向。
4. 每次只调整少数变量，例如“保留构图，改为暖色晨光”，保持迭代可控。
5. 交付前检查画面边缘、手部/文字、品牌元素、留白和裁切安全区。

## 提示词结构

`用途与比例 + 主体 + 场景 + 构图 + 光线/色彩 + 风格/材质 + 负面限制`。

示例：`电商方形主图，一瓶无标签玻璃冷萃咖啡置于浅米色背景的木桌中央，右侧留白，晨间柔光，真实商业摄影，极简高级，无文字、无人像、无水印。`

## 安全与工具边界

仅在可用且已授权的 Image2 图像生成工具中生成或编辑。没有连接时，交付完整提示词、尺寸建议和版本清单。不得冒充真实人物、伪造证据，或未经授权使用受保护的品牌、肖像和作品。
