# 证据与归因规则

## 五类标签

- **[事实]**：书中可以直接核对的事件、数据或定义。
- **[作者主张]**：作者明确提出的判断、解释或建议。
- **[书中转引]**：作者引用的研究、他人观点或二手事件；记录书内位置不等于已核验外部原始来源。
- **[外部校验]**：书外的独立来源；必须给来源和日期。
- **[蒸馏推断]**：由多个段落综合得到，但作者没有直接这样说。
- **[争议/反例]**：书内限制、反例或另行核验的外部争议。
- **[证据不足]**：单个故事、无出处数据、材料缺失或不可读图表。

## 定位规则

优先顺序：印刷页码加章节名 > PDF页码加章节名 > EPUB章节/小节/段落 > 无分页文本的章节/段落/短定位语。给每个证据分配 `loc_id`，如 `C03-S02-P087`。扫描件或不同译本页码不稳定时，同时给版本信息。

禁止：

- 猜测页码。
- 把译者序、推荐序或封面文案当作者观点。
- 把一个案例写成普遍规律。
- 把书外常识塞回书中并说“作者认为”。
- 把多本书的观点混合后仍归给当前书。

## 置信度

- **高**：作者明确表述，且跨章节或由多项证据支持。
- **中**：作者明确表述但只出现一次，或依赖有限案例。
- **低**：基于结构、语气或间接材料推断。

冲突证据并列呈现，不用平均值掩盖分歧。
