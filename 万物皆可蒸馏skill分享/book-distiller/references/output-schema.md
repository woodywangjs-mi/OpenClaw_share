# 输出模板

## 快速判断

1. 这本书解决什么问题
2. 一句话主张
3. 三个值得读的观点
4. 最大局限
5. 适合谁、不适合谁
6. 是否值得阅读全文

## 标准蒸馏

1. **材料边界**：版本、完整度、定位方式
2. **全书要解决的问题**
3. **一条主论证链**
4. **3—7个核心模型**
   - 一句话说明
   - 书内证据位置
   - 作者如何推出它
   - 可迁移场景
   - 失效条件
5. **5—10条行动规则**
6. **关键案例与证据质量**
7. **矛盾、反例与未回答问题**
8. **给读者的最小行动**
9. **费曼检测题**

## 应用版

先复述用户的真实问题，再只选最相关的1—3个模型：

- 模型如何映射到当前问题
- 当前主约束
- 现在做什么
- 暂时不做什么
- 什么事实会改变建议

明确标记“这是基于本书框架的应用推断”。

## 教学版

1. 学习目标
2. 先修知识
3. 从具体例子进入
4. 三个核心概念
5. 一个错误示范或反例
6. 一个动手任务
7. 三道费曼检测题
8. 迁移任务

不要把标准蒸馏全文直接当课程稿。
