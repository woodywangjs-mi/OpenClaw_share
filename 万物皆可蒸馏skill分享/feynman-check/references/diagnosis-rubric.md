# 检测量表

在内部记录，不向用户展示打分表，除非用户要求。

## 总体证据等级

| 等级 | 名称 | 当前可观察证据 |
|---|---|---|
| L0 | 听说过 | 能认出术语，但不能独立解释 |
| L1 | 能说清 | 能用自己的话解释并给出具体例子 |
| L2 | 能做出 | 能完成最小真实任务并检查结果 |
| L3 | 能纠错和迁移 | 能定位错误、验证修复，并用于新场景 |

“能教别人”是横向证据，不自动等于最高等级。讲得好但没做过，最多只能证明L1。

| 能力 | 已通过 | 基本通过但不稳定 | 尚未通过 | 未检测 |
|---|---|---|---|---|
| 解释 | 能用自己的话讲清输入、机制、结果和前提 | 主线正确但依赖术语或漏一项 | 循环定义、背诵或因果错误 | 尚未提问 |
| 区分 | 能辨别相近概念、反例与边界 | 常见情况能分，边缘情况不稳 | 只认关键词，换问法就错 | 尚未提问 |
| 实作 | 能独立产出可检查结果 | 需要少量提示 | 不知道下一步或无法判断结果 | 尚未提问 |
| 排错 | 能定位原因、提出修复并验证 | 能看出错但解释或验证不足 | 只重做，不知道为什么 | 尚未提问 |
| 迁移 | 能把原理用于改变条件的新场景 | 能迁移到相近场景 | 只能复现原例或固定步骤 | 尚未提问 |

## 诊断归因

不要笼统写“理解不深”。优先归入：

- **概念缺口**：关键机制或关系错误。
- **区分缺口**：无法区分相近概念、条件或反例。
- **步骤缺口**：知道原理但不会执行。
- **反馈缺口**：不会判断结果是好是坏。
- **排错缺口**：失败后找不到原因。
- **迁移缺口**：只能照抄原步骤。
- **表达缺口**：会做但难以说清；不能直接等同于不会。

## 停止条件

- 已找到一个决定性的上游缺口，后续关卡会被它全部污染：暂停并补课。
- 五项能力均有足够证据：结束检测。
- 用户目标只要求较低层级能力：达到目标后结束，不强迫通过所有关卡。
- 对话无法验证真实操作：标记“未检测”，不要推断通过。
