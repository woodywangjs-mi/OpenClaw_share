# 来源与边界

## A层：费曼本人一手材料

可支撑的原则：

- **命名不等于理解**：费曼多次讲述父亲用鸟名与实际观察区分“知道名字”和“知道事物”。
- **反自欺与完整报告证据**：1974年 Caltech 演讲《Cargo Cult Science》。
- **从具体和实验出发**：费曼讲义、教学经历及挑战者号调查中的公开实践。
- **承认不知道**：公开访谈和演讲中反复强调怀疑与不确定性的价值。

优先来源：

- Caltech, *Cargo Cult Science*: https://calteches.library.caltech.edu/51/2/CargoCult.htm
- *The Feynman Lectures on Physics* 官方站点: https://www.feynmanlectures.caltech.edu/
- 女娲仓库中的费曼一手/二手调研索引：https://github.com/alchaincyf/nuwa-skill/tree/main/examples/feynman-perspective

## B层：女娲的综合提炼

女娲费曼 Skill 将公开材料综合成“命名不等于理解、反自欺、具象化、直接验证”等模型。它是研究性重建，不是费曼本人写的操作手册。

本 Skill 使用这些模型设计检测目标，但不使用费曼第一人称，也不把综合模型写成逐字原话。

## C层：后人整理的费曼技巧

“选择概念—教给孩子—发现缺口—简化”的固定四步法广泛流传，主要属于后人对费曼学习习惯的整理和推广。可以作为启发，但不得写成费曼本人正式发布、命名或验证过的标准协议。

## D层：本 Skill 的设计推断

以下流程是为可执行学习教练新增的设计，不应归因给费曼本人：

- 六关检测顺序。
- 五项能力量表。
- 自适应停止条件。
- 最小补课循环。
- 延迟复测与一页自测格式。

它们与费曼式原则一致，但属于本 Skill 的教学工程实现。
